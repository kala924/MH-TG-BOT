# 🤖 MH-TG-BOT

Multilingual AI Telegram Assistant.

## Features

- 🌍 Multilingual support
- 💬 AI conversation
- 🧠 Conversation memory
- ⚙️ Commands
- 🔘 Inline buttons
- 👤 User preferences

## Commands

/start
/help
/language
/clear
/about

## Environment Variables

BOT_TOKEN=your_telegram_bot_token
AI_API_KEY=your_ai_api_key

Never publish API keys or BotFather tokens.
